---
title: "Stop Training"
openapi: 'image-generation/train-model/openapi.json POST /stop'
description: 'Stop a queued or running training run and end its hourly billing.'
---

Stops a run that is queued or training. Billing ends straight away; if the current hour had not been charged yet, that hour is charged. A run that has already finished or failed cannot be stopped and keeps its result.

## Request

Make a `POST` request to the endpoint below with the training `id` from [Start Training](/image-generation/train-model/start-training).

```bash
POST https://modelslab.com/api/v6/trainer/stop
```

### Body
```json json
{
    "key": "your_api_key",
    "training_id": "9b2f6c1e-4d3a-4f8e-a1b2-3c4d5e6f7a8b"
}
```

## Response

```json json
{
    "status": "success",
    "message": "training stopped"
}
```

| Error message | Meaning |
| :--- | :--- |
| `Training request not found.` | No run with this `id` belongs to your account. |
| `Training has already finished.` | The run completed or failed before you stopped it. |

<Note>
  A stopped run reads `training_completed` on the [status endpoint](/image-generation/train-model/training-status).
</Note>
