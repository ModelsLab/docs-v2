Trains a LoRA for **MOSS Image**. Like the Stable Diffusion trainer it takes an `instance_prompt` and exposes the LoRA settings. The LoRA is uploaded to your Hugging Face account for you to download.

<Info>
  New to Train Master? Read the [overview](/image-generation/train-master/overview) for what you need first (Hugging Face token, images, wallet balance) and how billing works.
</Info>

## Request

Send a `POST` request to the [Start Training](/image-generation/train-master/start-training) endpoint with `trainer_id` set to `moss-image-lora-trainer`.

```bash
POST https://modelslab.com/api/v6/trainer/train
```

### Body
```json json
{
    "key": "your_api_key",
    "trainer_id": "moss-image-lora-trainer",
    "images": [
        "https://raw.githubusercontent.com/pnavitha/sampleImages/master/1.png",
        "https://raw.githubusercontent.com/pnavitha/sampleImages/master/2.png",
        "https://raw.githubusercontent.com/pnavitha/sampleImages/master/3.png",
        "https://raw.githubusercontent.com/pnavitha/sampleImages/master/4.png",
        "https://raw.githubusercontent.com/pnavitha/sampleImages/master/5.png",
        "https://raw.githubusercontent.com/pnavitha/sampleImages/master/6.png",
        "https://raw.githubusercontent.com/pnavitha/sampleImages/master/7.png",
        "https://raw.githubusercontent.com/pnavitha/sampleImages/master/8.png",
        "https://raw.githubusercontent.com/pnavitha/sampleImages/master/9.png"
    ],
    "instance_prompt": "photo of sks man",
    "hf_username": "your_hf_username",
    "hf_token": "hf_your_write_token",
    "training_steps": 1500,
    "resolution": 1024,
    "seed": 298329,
    "batch_size": 4,
    "mixed_precision": "fp16",
    "rank": 4,
    "alpha": 2,
    "learning_rate": 0.005
}
```

Your LoRA is uploaded to `https://huggingface.co/{hf_username}/{id}`, where `id` is the training ID returned by this request. Save the `id` from the response to [check the status](/image-generation/train-master/training-status) or [stop the run](/image-generation/train-master/stop-training).

## Body Attributes

<ParamField body="key" type="string" required>
  Your API key. Get one from your [dashboard](https://modelslab.com/dashboard/api-keys).
</ParamField>

<ParamField body="trainer_id" type="string" required>
  Must be `moss-image-lora-trainer`.
</ParamField>

<ParamField body="images" type="string[]" required>
  Public URLs of your training images, **1 to 100**. Every URL is downloaded before training starts, and the request fails if any of them needs a login or is not an image. 10 to 30 images work well.
</ParamField>

<ParamField body="instance_prompt" type="string" required>
  A short prompt naming your subject with a unique token, e.g. `photo of sks man`. Use the same phrase in your prompts when you generate. Up to 2,000 characters.
</ParamField>

<ParamField body="hf_username" type="string" required>
  Your Hugging Face username. The LoRA is uploaded to a repo under this account.
</ParamField>

<ParamField body="hf_token" type="string" required>
  A Hugging Face access token starting with `hf_`, with **write** access. Create one at [huggingface.co/settings/tokens](https://huggingface.co/settings/tokens).
</ParamField>

<ParamField body="training_steps" type="integer">
  How long to train. Start with 100 to 150 steps per image (10 images × 150 = 1,500). Values above **2,000** are trained at 2,000. Recommended: `1500`.
</ParamField>

<ParamField body="resolution" type="integer">
  Resolution the images are trained at, from 512 to 1024. Recommended: `1024`.
</ParamField>

<ParamField body="seed" type="integer">
  Random seed, up to 999999. Use the same seed to make a run reproducible.
</ParamField>

<ParamField body="batch_size" type="integer">
  Images processed per step, 1 to 128. Recommended: `4`.
</ParamField>

<ParamField body="mixed_precision" type="string">
  Training precision. Only `fp16` is supported.
</ParamField>

<ParamField body="rank" type="integer">
  LoRA rank, 1 to 512. Higher learns more detail and makes a bigger file. Recommended: `4`.
</ParamField>

<ParamField body="alpha" type="integer">
  LoRA alpha (scaling), 1 to 1024. Usually half of `rank` or equal to it. Recommended: `2`.
</ParamField>

<ParamField body="learning_rate" type="number">
  How fast the model learns, up to 0.01. Recommended: `0.005`.
</ParamField>

## Use your LoRA

When the [status endpoint](/image-generation/train-master/training-status) reports `training_completed`, your LoRA is in your Hugging Face repo:

```bash
https://huggingface.co/{hf_username}/{id}
```

<Note>
  LoRAs from this trainer are not loaded for inference on ModelsLab yet, so `data.inference` reports `failed`. Download the `.safetensors` file from your repo to use it.
</Note>
