title: "Training Status"
openapi: 'image-generation/train-master/openapi.json POST /status/{training_id}'
description: 'Check the progress of a training run and get the request that runs your trained LoRA.'
---

Returns the status of a training run. Poll it every minute or two. After the run completes, keep polling until `data.inference.status` is `ready`; the response then contains the exact request to generate with your LoRA.

## Request

Make a `POST` request to the endpoint below, with the training `id` from [Start Training](/image-generation/train-master/start-training) in the path.

```bash
POST https://modelslab.com/api/v6/trainer/status/{training_id}
```

### Body
```json json
{
    "key": "your_api_key"
}
```

## Status values

| `message` / `data.status` | Meaning |
| :--- | :--- |
| `training_started` | Queued or training. |
| `training_completed` | Training finished, or you stopped the run. |
| `training_cancelled` | Training failed. `data.response_dump` holds the reason. |

</Note>
