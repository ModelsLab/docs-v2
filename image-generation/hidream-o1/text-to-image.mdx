---
title: "Text to Image"
openapi: 'POST /text2img'
description: 'Create high quality images from text using the HiDream O1 model.'
---

Generate photorealistic images from text descriptions using the HiDream O1 model. HiDream O1 excels at creating highly detailed, realistic images with excellent prompt adherence.

<Note>
Use `hidream-o1` as the `model_id` when calling this endpoint.
</Note>
