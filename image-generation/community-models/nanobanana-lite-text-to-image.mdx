---
title: "NanoBanana Lite Text to Image"
description: "Generate images from text prompts using the NanoBanana Lite – Pretrained testing model."
---

<Info>
This endpoint routes to the testing inference server at `fpuinklnizer-3754.proxy.gpulab.ai`.
</Info>

## Request

```bash
POST https://modelslab.com/api/v8/images/nanobanana-lite-run
```

## Body

```json
{
  "key": "your-api-key",
  "model_id": "nanobanana-lite-pretrained",
  "prompt": "A serene mountain landscape with a crystal clear lake",
  "negative_prompt": "(worst quality:2), (low quality:2), blurry, nsfw",
  "width": 1024,
  "height": 1024,
  "samples": 1,
  "webhook": null
}
```

## Body Attributes

<ParamField body="key" type="string" required>
  Your ModelsLab API key.
</ParamField>

<ParamField body="model_id" type="string" required>
  Must be `nanobanana-lite-pretrained`.
</ParamField>

<ParamField body="prompt" type="string" required>
  Text description of the image to generate.
</ParamField>

<ParamField body="negative_prompt" type="string" default="(worst quality:2), (low quality:2), blurry, nsfw">
  Things to avoid in the generated image.
</ParamField>

<ParamField body="width" type="integer" default="1024">
  Image width. Must be between `512` and `2048` (step `8`).
</ParamField>

<ParamField body="height" type="integer" default="1024">
  Image height. Must be between `512` and `2048` (step `8`).
</ParamField>

<ParamField body="samples" type="integer" default="1">
  Number of images to generate. Must be between `1` and `4`.
</ParamField>

<ParamField body="webhook" type="string">
  URL to receive a webhook callback when generation completes.
</ParamField>
