---
title: "hidream-O1 Text to Image"
description: "Generate images from text prompts using the hidream-O1 testing model."
---

<Info>
This endpoint routes to the testing inference server at `fpuinklnizer-3754.proxy.gpulab.ai`.
</Info>

## Request

```bash
POST https://modelslab.com/api/v8/images/hidream-o1-run
```

## Body

```json
{
  "key": "your-api-key",
  "model_id": "hidream-o1",
  "prompt": "A futuristic cityscape at night, neon lights reflecting on wet streets",
  "negative_prompt": "(worst quality:2), (low quality:2), blurry, nsfw",
  "width": 1024,
  "height": 1024,
  "samples": 1,
  "webhook": null
}
```

## Body Attributes

<ParamField body="key" type="string" required>
  Your ModelsLab API key.
</ParamField>

<ParamField body="model_id" type="string" required>
  Must be `hidream-o1`.
</ParamField>

<ParamField body="prompt" type="string" required>
  Text description of the image to generate.
</ParamField>

<ParamField body="negative_prompt" type="string" default="(worst quality:2), (low quality:2), blurry, nsfw">
  Things to avoid in the generated image.
</ParamField>

<ParamField body="width" type="integer" default="1024">
  Image width. Must be between `512` and `2048` (step `8`).
</ParamField>

<ParamField body="height" type="integer" default="1024">
  Image height. Must be between `512` and `2048` (step `8`).
</ParamField>

<ParamField body="samples" type="integer" default="1">
  Number of images to generate. Must be between `1` and `4`.
</ParamField>

<ParamField body="webhook" type="string">
  URL to receive a webhook callback when generation completes.
</ParamField>

## Response

### Processing

<ResponseField name="status" type="string">
  Always `processing` on initial submission.
</ResponseField>

<ResponseField name="id" type="string">
  Unique request ID. Use this to fetch results later.
</ResponseField>

<ResponseField name="eta" type="integer">
  Estimated time to completion in seconds.
</ResponseField>

<ResponseField name="fetch_result" type="string">
  URL to poll for the completed result.
</ResponseField>

```json
{
  "status": "processing",
  "id": "123456789",
  "eta": 40,
  "message": "Try to fetch request after seconds estimated",
  "tip": "Your image is processing in background, you can get this image using fetch API",
  "fetch_result": "https://modelslab.com/api/v8/images/fetch/123456789",
  "meta": {},
  "future_links": []
}
```
