---
title: "Voice Cloning"
openapi: 'POST /voice/text_to_audio'
description: 'Generate audio from text by cloning a provided audio URL or a selected voice ID.'
---

## Request
Make a `POST` request to below endpoint and pass the required parameters as a request body.

<Note>
`init_audio` is required for voice cloning. You can also pass `voice_id` to select a voice from the available voice list.
</Note>

```curl curl
--request POST 'https://modelslab.com/api/v6/voice/text_to_audio' \
```

## Body 
```json json
{
  "key": "your_api_key", 
  "prompt":"Narrative voices capable of pronouncing terminologies & acronyms in training and ai learning materials.", 
  "init_audio":"https://assets.modelslab.ai/generations/5c3eef10-0eb4-4db8-8b12-fc4eedbf30b9.mp3", 
  "voice_id": "your_voice_id",
  "language":"english", 
  "webhook": null, 
  "track_id": null
}
```

## Drama 3
Pass `"model_id": "drama-3"` to generate with Drama 3. It detects the spoken language itself, so `language`, `emotion` and `speed` are ignored. The reference clip must be at least 3 seconds long, and you can pass its transcript as `reference_text` for a closer match.

```json json
{
  "key": "your_api_key",
  "model_id": "drama-3",
  "prompt": "Hello! This is a test of the Drama three audio model.",
  "init_audio": "https://assets.modelslab.ai/generations/5c3eef10-0eb4-4db8-8b12-fc4eedbf30b9.mp3",
  "reference_text": "Transcript of the reference clip.",
  "language": "english",
  "temperature": 1.0,
  "top_p": 0.9,
  "top_k": 30,
  "max_new_tokens": 1024,
  "seed": 123,
  "webhook": null,
  "track_id": null
}
```
