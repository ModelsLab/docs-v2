---
title: "Create Dubbing"
openapi: 'POST /voice/create_dubbing'
description: 'The endpoint enables automatic dubbing of videos from one language to another'
---

## Request
Make a `POST` request to below endpoint and pass the required parameters as a request body.

```curl curl
--request POST 'https://modelslab.com/api/v6/voice/create_dubbing' \
```
<Tip>
You can find all voice_id [here](https://modelslab.com/trained-voice-lists).
</Tip>

## Body

```json json
{
  "key": "your_api_key",
  "init_video": "https://assets.modelslab.ai/generations/61cf206f-8bbe-498d-9514-a521c2833547.mp4",
  "source_lang": "hi",
  "output_lang": "en-us",
  "voice_id":"henry",
  "speed": 1.0,
  "file_prefix": "spanish_dub",
  "base64": false,
  "webhook": null,
  "track_id": null
}

```
