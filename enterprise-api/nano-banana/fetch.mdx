## Request
Send a `POST` request to below endpoint to fetch a queued image.
```curl curl
--request POST 'https://modelslab.com/api/v1/enterprise/nano_banana/fetch/{id}' \
```

## Body
```json json
{
    "key": "enterprise_api_key"
}
```
