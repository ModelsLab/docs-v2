---
title: "Fetch Image"
description: "Fetch Queued Image."
openapi: "POST /nano_banana/fetch/{id}"
---

Send a `POST` request to retrieve the corresponding queued images. The `{id}` is the ID returned together with the image URL in the generation response. This endpoint does not generate new images — it returns already generated or queued images.
