---
title: "Multi Reference"
description: "Generate images from text with multiple reference images using nano banana model."
openapi: "POST /nano_banana/multi_ref"
---

Generate images from a text prompt combined with multiple reference images using the Nano Banana model.

<Note>
The `ref_image` parameter accepts an array of image URLs for multi-reference composition.
</Note>
