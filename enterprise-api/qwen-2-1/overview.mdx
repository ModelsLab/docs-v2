Qwen Edit 2.1 runs directly on your own enterprise container — requests are posted straight at your
dedicated server instead of going through the shared queue.

One model serves both generating an image from a prompt and editing images you send it. Image to
image takes up to **10 reference images** in a single request.

| Capability | Endpoint |
| --- | --- |
| Text to image | `/qwen_edit_2_1/text2img` |
| Image to image | `/qwen_edit_2_1/img2img` |
