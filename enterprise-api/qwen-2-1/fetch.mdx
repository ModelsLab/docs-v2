---
title: "Fetch Image"
description: "Fetch Queued Images API fetches queued images for Qwen Edit 2.1."
openapi: "POST /qwen_edit_2_1/fetch/{id}"
---

## Request
Send a `POST` request to below endpoint to return the corresponding queued images. Where `{id}` is the ID returned together with the image URL in the response upon its generation. This endpoint does not generate a new image, it returns already generated/queued images.
```curl curl
--request POST 'https://modelslab.com/api/v1/enterprise/qwen_edit_2_1/fetch/{id}' \
```

## Body
```json json
{ 
    "key": "enterprise_api_key"
}
```
