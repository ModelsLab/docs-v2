---
title: "Fetch Image"
description: "Fetch Queued Images API fetches queued images for Krea 2 Turbo."
openapi: "POST /krea_2_turbo/fetch"
---

## Request
Send a `POST` request to below endpoint to return the corresponding queued images.
```curl curl
--request POST 'https://modelslab.com/api/v1/enterprise/krea_2_turbo/fetch/{id}' \
```

## Body
```json json
{ 
    "key": "enterprise_api_key"
}
```
